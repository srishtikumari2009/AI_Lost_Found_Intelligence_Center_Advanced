# AI Lost & Found Intelligence Center

An AI-based image matching system that helps users find lost items by matching images of lost and found objects.

## Features

- Upload lost item images
- Upload found item images
- Match images using AI
- Store item details
- Simple and user-friendly interface

## Technologies Used

- Python
- Tkinter
- Pillow
- Image Matching

## How to Run

1. Install required libraries.
2. Run main.py.
3. Upload lost and found item images.
4. Check matching results.
